# Design decisions — 2026-09-30

Decisions that unblock the delegated fixes in [REVIEW-2026-09-30.md](REVIEW-2026-09-30.md).
Each is written so it can be implemented without further discussion.

---

## 1. One validity mask per zone when merging (fixes A2 / Astra §4.2, §4.3)

**Problem.** `reproject_datatree` merges zones variable by variable, each with its own mask. For
int8 data without a nodata attr the mask can never be true, and for TESSERA the `embeddings` and
`scales` of one pixel can come from different zones.

**Decision.** A pixel is taken from exactly one zone, for *all* its variables.

1. Define `_pixel_validity(ds) -> DataArray[bool]` with dims `(time, y, x)` (no `band`):
   - `scales` present (raw TESSERA): `np.isfinite(ds.scales)`.
   - otherwise the `embeddings` variable:
     - integer dtype with a `nodata`/`_FillValue` attr: `(emb != nodata).any("band")`;
     - float dtype: `emb.notnull().any("band")`;
     - integer dtype with **no** nodata attr: `raise ValueError` naming the zone and variable.
       Never fall back to `isnull()` on an integer array.
2. Before merging, align the zones' non-spatial coordinates: outer-join `time` (and `band` if
   they differ), filling each variable with its own nodata (integer: its nodata attr; float: NaN;
   `scales`: NaN). This replaces the current shape check that raises when year coverage differs.
3. Merge:
   ```python
   take = ~valid_combined & valid_next          # (time, y, x)
   for var in union_of_data_vars:               # not just zone 0's vars (A9)
       combined[var] = xr.where(take, next_ds[var], combined[var], keep_attrs=True)
   valid_combined = valid_combined | valid_next
   ```
   `xr.where` broadcasts `take` over `band`. The operation stays elementwise, so chunks are preserved.
4. For now `_pixel_validity` lives in `utils.py`. Once the Collection work (decision 3) lands it
   becomes `collection.validity(ds)`.

**Tests.** Astra's case: zone 1 has code 0 with scale NaN, zone 2 has code 10 with scale 2 → the
result is code 10, scale 2, value 20. Two zones with different year sets merge without raising. An
int8 zone with no nodata attr raises.

## 2. Index query API and the smaller download (C1, B1, B2, B4)

**Decisions.**

- **Keep `async def query`** for upstream compatibility (the fork calls itself a drop-in
  replacement). Add a **synchronous `AEFIndex.search(...)`** with the same arguments;
  `query` becomes a one-line wrapper around it. The README and notebooks use `search`.
- **`download()` fetches only the needed columns** (`fid, crs, path, year, utm_zone, utm_*,
  wgs84_*`, about 8.7 MB instead of 78 MB). It reads column chunks with ranged reads (pyarrow
  `ParquetFile` over an obstore-backed file object) and writes a slim local parquet named
  `aef_index_<source>.v2.parquet`. The `v2` suffix means an old full-size cache is never mistaken
  for the new one.
- **`load()` returns a plain `pandas.DataFrame`**, with no geometry column and no geopandas.
  `geopandas` and `shapely` move to the `[exact]` extra, which also removes the import cost (B4).
- **The default filter is bbox overlap** on the four `wgs84_*` columns, done with numpy on the
  302k rows. It can return a few extra edge tiles but never misses one. Those extra tiles are
  cropped to nothing and skipped by the reader (fix S3).
- **`search(..., exact=True)`** additionally fetches the `geom` column (another ~62 MB), cached
  separately, and applies the true footprint intersection to the candidate tiles only. Results
  are identical to today's `intersects`.
- Result order stays as today: file row order, then `limit`. `limit` must be `None` or ≥ 0 (A8).
- The download is written atomically (temp file + `replace`). `force=True` also clears the loaded
  table (§4.15).
- The default cache folder is the per-user cache directory from `platformdirs` (B3), not `/tmp`.

**Tests.** On a synthetic index, `search` returns a superset of the exact result and matches it
with `exact=True`. `limit=0` returns `[]`. The downloader requests only the listed columns (mock
the file object and record which byte ranges are read).

## 3. Collection abstraction (D1): interface only, implemented after the fixes above

```python
@dataclass(frozen=True)
class Collection:
    name: str                       # "aef-v1", "tessera-v1.1"
    band_names: Callable[[int], list[str]]
    nodata: int | float | None      # raw-encoding sentinel, None if validity comes from elsewhere
    encoding: Literal["aef-sqrt", "codes-times-scales", "float"]
    dequantize: Callable[[xr.Dataset], xr.Dataset]
    validity: Callable[[xr.Dataset], xr.DataArray]   # decision 1
    zone_crs: Callable[[str], str]  # "31N" -> "EPSG:32631"
```

- The reader's `A00..` band naming, `set_aef_nodata`, the `-128` join fill and the
  `_is_quantized` guard all read their values from the collection instead of module constants.
- Each dataset records its encoding in a variable attr (`aef:encoding`), and the resampling guard
  checks that attr rather than the dtype (Astra §4.11).
- Built-ins are `AEF` and `TESSERA`. Entry points (D9) come later.

This is scheduled after S17/S18 so the refactor starts from correct behaviour and can be checked
against it.
